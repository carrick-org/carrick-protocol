# Example memory repository

A small, made-up memory repository that follows chapter 2 of the specification. It shows a
pinned note with aliases, a decision that supersedes another, a retracted fact, a person and an
entity with typed links, a thread, a proposal in `_inbox/`, a digest, and a relation registry.

Check it with:

    python3 conformance/carrick_conformance.py repo examples/memory-repo
